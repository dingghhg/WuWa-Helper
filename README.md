# WuWa Helper

Сайт-помощник для игроков Wuthering Waves. Работает в любом браузере, на телефоне и ПК, в том числе у тех, кто играет через облако. С игрой никак не взаимодействует (никакого чтения памяти и автоматизации), поэтому риска бана нет.

## Что умеет
- **Пластины**: считает, когда накопится нужное число волновых пластин (1 за 6 минут, максимум 240), и напоминает.
- **Задания**: ежедневный и недельный чек-лист со сбросом в 04:00 по времени вашего сервера. Задания можно добавлять и удалять.
- **Крутки**: считает шанс получить нужного 5★ персонажа (нужное число копий) по вашим конвенам и астритам, с учётом гаранта и 50/50.

Все данные хранятся в браузере (localStorage), аккаунт не нужен.

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com (например `wuwa-helper`), публичный.
2. Нажмите **Add file → Upload files** и загрузите все 4 файла: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg` (README можно тоже). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/wuwa-helper/`.
5. На телефоне откройте ссылку и выберите «Добавить на главный экран» — получится как обычное приложение.

## Как обновлять
Просто загрузите новую версию `index.html` в репозиторий (замена файла). Сайт обновится сам.

## Если игра поменяла правила круток
Откройте на вкладке «Крутки» блок «Настройки шансов» и поменяйте значения (базовый шанс, мягкий и жёсткий гарант, шанс 50/50). Значения по умолчанию приблизительные, сверьте их с игрой.

## Ограничения
- Уведомления приходят, пока сайт открыт во вкладке. Закрытый сайт сам уведомить не может (для этого нужен сервер).
- На iPhone уведомления работают только после добавления сайта на главный экран.

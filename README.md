# WuWa Helper

Сайт-помощник для игроков Wuthering Waves. Работает в любом браузере на телефоне и ПК, в том числе у тех, кто играет через облако. С игрой никак не взаимодействует (никакого чтения памяти и автоматизации), поэтому риска бана нет.

## Что умеет
- **Пластины**: счётчик X / 240 (1 пластина за 6 минут), быстрые кнопки +20 / +60 / −40 / −60, таймер до следующей пластины, до 240 (с временем вида «Full at 18:42») и до вашей цели (например, 180). Когда цель достигнута: звук, сообщение на экране и push-уведомление.
- **Задания**: ежедневный и недельный чек-лист, таймеры до сброса (04:00 по времени сервера Europe / America / Asia / SEA), свои задачи, кнопка «Сбросить все галочки» и автосброс.
- **Крутки**: астриты и крутки в шанс получить цель от S0 до S6, с учётом мягкого и жёсткого гаранта и 50/50. Показывает гарантированный результат, худший сценарий, чего не хватает, и график шанса. Настройки шансов можно менять.
- **Прокачка**: планировщик материалов (сколько заходов и пластин нужно и когда накопите) и памятка по дням недели.
- **Данные**: экспорт и импорт в JSON, полный сброс.

Всё хранится в браузере (localStorage), аккаунт не нужен.

## Файлы
`index.html` (вся программа), `sw.js` (работа без интернета и уведомления), `manifest.webmanifest` и `icon.svg` (установка как приложение).

## Как выложить на GitHub Pages
1. Создайте публичный репозиторий на github.com (например `wuwa-helper`).
2. **Add file → Upload files**, загрузите все файлы из этой папки и нажмите **Commit changes**.
3. **Settings → Pages**: *Deploy from a branch*, ветка **main**, папка **/ (root)**, **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-НИК.github.io/wuwa-helper/`.
5. На телефоне откройте ссылку и выберите «Добавить на главный экран».

Обновлять просто: заменяйте файлы в репозитории новой версией.

## Важно
- Шансы круток по умолчанию (0.8%, мягкий гарант с 65-й, жёсткий на 80-й, 50/50) приблизительные. Сверьте с игрой и при необходимости поправьте в «Крутки → Настройки шансов».
- Стоимость захода в планировщике по умолчанию 40 пластин. Поменяйте под своё подземелье.
- Уведомления приходят, пока сайт открыт во вкладке или установлен как приложение. Закрытый сайт сам уведомить не может. На iPhone уведомления работают только после добавления сайта на главный экран.
- Данные у каждого устройства свои. Чтобы перенести, используйте экспорт и импорт.
